# Amika Gail Martija – Portfolio (Vite + React)

    npm install
    npm run dev
    npm run build   # outputs a single dist/index.html (photo, CSS and JS inlined)

Content lives at the top of `src/App.jsx` (JOBS, CAPS, ACH, FAQ). Replace `src/photo.jpg` to change the portrait.
Deploy on Netlify: `netlify.toml` sets the build command and publish folder.
